# Feature and permission matrix

“Shell” means the module is visible but deliberately unavailable; it is not complete.

| Module / capability          | Salesforce API                                | Typical access needed                      | Phase 1 status                                                                                                                          |
| ---------------------------- | --------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| Current-session identity     | `sid` cookie / Identity / REST                | Signed-in Salesforce tab and API access    | Implemented; real-org verification pending                                                                                              |
| OAuth fallback               | OAuth 2.0 / Identity                          | External Client App authorization          | Implemented; API Access Control test pending                                                                                            |
| Multi-org selector/isolation | Local extension + org/user identity           | Current browser sessions or OAuth          | Implemented; two-real-org test pending                                                                                                  |
| Org Info identity            | REST Query `Organization`, `/services/data/`  | API Enabled; readable Organization fields  | Implemented with current release label and latest API version                                                                           |
| Org limits                   | REST `/limits`                                | API Enabled; returned limits vary          | Implemented with unavailable state                                                                                                      |
| User-license usage           | REST Query `UserLicense`                      | View Setup and Configuration               | Implemented with used, available, total, status, utilization, and a permission-aware unavailable state                                  |
| SOQL query                   | REST `/query`                                 | API Enabled plus object/field access       | Implemented                                                                                                                             |
| SOQL pagination              | REST query locator                            | Same as original query                     | Implemented; origin pinned                                                                                                              |
| Tooling query                | Tooling `/query`                              | API Enabled and Tooling/object permissions | Implemented                                                                                                                             |
| Records inspect/search       | UI API / REST sObject Rows / Describe         | Object, record, field permissions          | Implemented: automatic standard/custom Lightning/Classic lookup, all accessible fields and search                                       |
| Records writes               | REST/UI API                                   | CRUD/FLS/sharing plus confirmations        | Phase 2                                                                                                                                 |
| Export                       | REST Query                                    | Object and field permissions               | Preview: CSV/JSON up to 5,000 loaded rows                                                                                               |
| Import                       | Local CSV / REST sObject Collections          | CRUD/FLS, sharing, validation, automation  | Beta: create/update/delete, mapping, preflight, explicit irreversible/production confirmation, per-row results; 2,000-row browser limit |
| Run-Apex                     | Tooling execute anonymous                     | Author Apex and API Enabled                | Beta: guarded execution; latest logs remain in the dedicated Debug Logs tab                                                             |
| Debug Logs                   | Tooling Query / ApexLog Body                  | Apex/log visibility varies                 | Implemented: inline viewer and bounded body search                                                                                      |
| Code Coverage                | Tooling coverage and asynchronous Test Runner | Apex/test execution visibility varies      | Implemented: org-wide and per-file percentages, line totals, guarded Run All Tests, live status, failures, and automatic refresh        |
| Users / Access               | REST Query                                    | Setup/user/permission visibility varies    | Preview: read-only lists                                                                                                                |
| Installed Packages           | Tooling `InstalledSubscriberPackage`          | API Enabled and package visibility         | Implemented: package, namespace, type, version, release and status                                                                      |
| Flows                        | Tooling `FlowDefinition`                      | API Enabled and Flow visibility            | Implemented: A–Z managed/unmanaged and active/inactive inventory with same-org Setup navigation                                         |
| Metadata                     | REST `/sobjects` and Describe                 | Object and field visibility                | Implemented: A–Z object/field schema plus child-relationship metadata                                                                   |
| App Tabs                     | REST `/tabs`                                  | Tabs visible to current user               | Implemented: A–Z list with same-org navigation links                                                                                    |
| Integrations                 | REST / Tooling / Metadata `listMetadata`      | Setup and metadata visibility varies       | Implemented: Connected Apps, External Client Apps, Named Credentials, External Credentials, and same-org Setup navigation; no secrets   |
| AI Agent                     | OpenAI / Anthropic / Gemini / Bedrock         | Provider key plus Salesforce access        | Preview: relationship-aware retrieval, retained evidence, answer gating, and an in-extension capabilities/limits/current-record guide   |
| Repository context           | Future GitHub / Azure / Bitbucket API         | Separate repository authorization          | Deferred until after initial store review                                                                                               |
